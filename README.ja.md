# 👻 Ghostkeeper Maze 3D — やさしいハロウィン迷路アドベンチャー

**小さな精霊を 3 匹見つけ、月明かりを借りて、みんなで家に帰ろう。** Ghostkeeper Maze 3D は [Crazy 3D](https://crazy3d.org/) のために作られた一人称視点のハロウィン迷路です。石の廊下を歩き、かぼちゃランタンの精霊と真鍮の鍵を集め、月の門を開きます。12 の夜と毎日の迷路を、地図や親切なおばけの案内でゆっくり探索できます。

**[今すぐ遊ぶ](https://halloween-haunted-maze.crazy3d.org/)** · [ハロウィンゲーム集](https://github.com/AshinTop/halloween-games) · [埋め込みガイド](EMBEDDING.md) · [設計ノート](DESIGN.md)

**README の言語：** English、简体中文、Español、Português (Brasil)、日本語。**ゲーム内の表示は英語と簡体字中国語のみ**です。日本語などの README があっても、ゲームのメニューがその言語に対応しているわけではありません。

![石の廊下を一人称で見る Ghostkeeper Maze 3D。小地図と移動ボタンを配置](docs/images/gameplay.jpg)

## 安心して歩ける夜 🎃

- **全 12 の冒険**。7×7 から 15×15 の迷路に加え、日付で決まる 11×11 のデイリーがあります。
- 奥行きのある壁、壁の裏に隠れる精霊、遠くの霧、月明かり、ランタンの光。
- 歩くと広がる小地図、任意の全体地図、残った目的地への案内。
- 最短歩数の目標、ローカル記録、音のオン・オフ、動きを減らす設定。
- 敵、追跡、突然の驚かし、時間制限、残機はありません。

## みんなを家へ連れて帰るには

かぼちゃランタンまで歩いて精霊を助け、鍵を取り、月の門に入りましょう。必要なのは**精霊 3 匹と鍵**です。早く門を見つけても失敗にはならず、まだ閉じているだけです。

移動はマス単位です。通れる隣のマスへ進むと 1 歩、その場で 90 度向きを変えても歩数は増えません。最短歩数は、すべての収集物を集めて出口へ入るまでの道のりです。門まで直行する距離ではありません。

| 夜 | 外周の壁を含む大きさ | 目標歩数 |
|---|---|---:|
| 1 | 7×7 | 16 |
| 2 / 3 / 4 | 9×9 | 32 / 34 / 40 |
| 5 / 6 / 7 | 11×11 | 60 / 54 / 48 |
| 8 / 9 / 10 | 13×13 | 94 / 76 / 84 |
| 11 / 12 | 15×15 | 102 / 104 |

## 操作

| 操作 | キーボード | タッチ・マウス |
|---|---|---|
| 前進・後退 | W または ↑ / S または ↓ | 前後ボタン |
| 左右に向きを変える | A または ← / D または → | 回転ボタン |
| 全体地図 | M | Map |
| おばけの案内 | H | Ghost |
| 夜の選択・再挑戦・共有 | Tab と Enter | 上部のボタン |

画面の移動ボタンは押し続けると繰り返せます。ポインターロック、ドラッグ、物理キーボードは不要です。

## 地図、案内、記録

小地図は歩くと近くの廊下を表示します。全体地図を初めて開くと、その冒険での**手助け 1 回**として記録されます。開き直しても増えません。おばけの案内は頼むたびに 1 回加算し、一番近い未取得の品、最後に出口への通れる道を示します。近くの目的地への案内であり、全収集順の最適解を保証する機能ではありません。品を取ると案内は消えます。

手助けを使ってもクリアできます。記録はまず手助けの少なさ、次に歩数で比較します。そのため、案内付きの短い道が、以前の手助けなしの記録を上書きすることはありません。クリア記録と設定を保存しますが、途中の位置は復元しません。

[夜 1](https://halloween-haunted-maze.crazy3d.org/#night=1) から夜 12、または[日付を決めたデイリー](https://halloween-haunted-maze.crazy3d.org/#daily=2026-10-31) を共有できます。デイリーは UTC 基準で、リンクは選んだ日付を保ちます。

## よくある質問

**全部の迷路をクリアできますか？** 生成時に道がつながるように作ります。全 12 夜の通しクリアをテストし、デイリーも同じ接続方式を使います。

**3D 表示に WebGL が必要ですか？** **Canvas 2D のレイキャスター**で、壁との交点と物体の奥行きを描画します。WebGL は不要です。

**ゆっくり歩いても大丈夫？** はい。追われることも時間切れもなく、地図と案内も使えます。

**アクセシビリティは？** 動きを減らす設定では滑らかなカメラ補間と装飾の動きを除きます。文章、所持数、状態表示はありますが、Canvas の空間全体をスクリーンリーダーで移動できるわけではありません。

## 自分のサイトに埋め込む

```html
<iframe src="https://halloween-haunted-maze.crazy3d.org/"
  title="Ghostkeeper Maze 3D"
  style="display:block;width:100%;height:540px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

想定する枠は 960×540、390×460、390×300、844×340 CSS ピクセルです。小型枠では大きな日誌を隠し、景色、所持品、地図、案内、移動ボタンを残します。特に背の低い親サイトでは iframe の実際の高さを確認してください。

公開版は、この GitHub リポジトリと連携して Cloudflare にデプロイされています。iframe に高さを指定し、親サイトのツールバー用の領域も確保してください。全画面ボタンは親サイト側で用意できます。詳細は [EMBEDDING.md](EMBEDDING.md) を参照してください。

## ローカルで実行・確認する

```sh
python3 -m http.server 4173
```

リポジトリのルートでサーバーを起動し、[http://localhost:4173/](http://localhost:4173/) を開きます。静的なゲームなので、ビルドや依存パッケージのインストールは不要です。`file://` では ES モジュールが読み込めない場合があるため、HTTP(S) を使用してください。テストには Node.js が必要です。

```sh
npm test
```

**10 件のテスト**で、つながった閉じた迷路、到達可能で重複しない品、全 12 夜の手順通りの勝利、独立した所持状態探索による目標値、衝突、門、取得、案内、日付、保存データ、壁の交点、物体の透視を確認します。

ゲームのソースはアカウント、外部 API、広告 SDK、外部素材 CDN を必要としません。記録はブラウザー内に保存され、クラウド同期はありません。Cloudflare が独自のホスティング用スクリプトやリクエストログを追加する場合があります。任意の合成音声はブラウザーの再生許可に従います。
